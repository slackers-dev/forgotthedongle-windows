# ForgotTheDongle for Windows

The Windows helper for [ForgotTheDongle](https://forgotthedongle.slackers.dev): the free iPhone app that turns your
phone into the presentation clicker, laser pointer, mouse, trackpad and keyboard of your PC.

**[Download the latest version](https://github.com/slackers-dev/forgotthedongle-windows/releases/latest/download/ForgotTheDongle.exe)**
(64-bit Windows 10 or 11, no installation or .NET needed) · [all releases](https://github.com/slackers-dev/forgotthedongle-windows/releases)

## Getting started

1. Get the iPhone app from the [App Store](https://apps.apple.com/app/forgotthedongle/id6813463726).
2. Start `ForgotTheDongle.exe`. The helper isn't code-signed yet: if Windows says "Windows protected your PC",
   choose **More info → Run anyway**. When the firewall asks, allow access on **private and public** networks.
3. The helper lives in the notification area (under the **^** next to the clock). Right-click it → **Add phone…**
4. In the iPhone app, pick this PC and type the 6-digit code it shows.

The phone and the PC talk directly over the local network. If the phone can't find the PC (office or guest Wi-Fi
often blocks devices from reaching each other), connect the PC to the iPhone's Personal Hotspot.

No account, no analytics, no cloud server. Privacy policy: https://forgotthedongle.slackers.dev/privacy.html

This repository only hosts the Windows downloads.
